# Hazard warning database

Apply the migrations in order before using the DMC warning workflow. Run them from the Supabase SQL Editor or with the Supabase CLI (`supabase db push`) after linking this project. The second migration removes the latitude and longitude columns from databases that already applied the initial schema. The third migration adds current water, rainfall, and slope readings plus historical chart samples.

The initial migration creates `hazards` and `hazard_warnings`, enables row level security, and inserts three repeatable sample hazard records for Colombo, Kandy, and Matara. The DMC assessment screen lists all active hazard records and shows water-level charts for floods or slope-movement and rainfall charts for landslides. Selecting a hazard carries it through coverage and warning preparation. Active hazard records and readings are publicly readable; issued warnings are publicly readable; creating warnings requires an authenticated user. Chosen distribution channels are stored in each warning's `channels` array. The app saves drafts and issued warning records, but does not send them to push, SMS, or siren gateways.
